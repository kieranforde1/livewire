# Livewire

Run cables so every town keeps its lights on. Connect generators to towns of the same colour with a limited supply of cable, and keep the grid from overloading as demand climbs.

A single-file canvas game (`index.html` + `game.js`) that works offline as a PWA. Open `index.html` or serve the folder with any static server.

Forked in spirit from the Byways engine, reskinned and heading towards its own power-grid mechanics (line capacity, day/night demand, storage).
